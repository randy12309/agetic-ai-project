---
name: screenshot-transcription
description: Reconstruct a document from overlapping screenshots as readable Markdown, preserving source details, document order and image-level traceability.
---

Inventory every image. Read in document order, using capture time, editor line numbers and overlapping phrases. Inspect screenshots that show other material, such as a repository tree, and give that material an appropriate place in the document.

Use local OCR as a draft when helpful. Read the original at native resolution, including the first and last visible rows. Compare adjacent views to recover clipped words, wrapped code and continuations. Sticky headings and duplicate captures help establish position. Render repeated document text once.

Restore the original heading hierarchy, paragraphs, lists, tables, diagrams and fenced examples. Preserve identifiers, casing, numbers, units, paths, negations, qualifications and the distinction between proposed work and recorded results. When corrections are requested, repair sentences from visible evidence. Mark an unreadable span when no capture resolves it.

Make a second pass from each image back to the finished document. Check examples, table cells, sentence boundaries and claims against the pixels. Retain conflicting historical notes with their context. Include a compact source index mapping each capture to its subject or visible line range. Verify the index against the image inventory and resolve its links from the destination file.
